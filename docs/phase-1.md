# 第一阶段开发说明

## 阶段目标

完成博客项目的基础展示能力与核心页面搭建，确保站点具备可访问、可展示、可扩展的初始形态。

## 范围

### 1. 核心页面

- 首页（个人展示、项目展示、动态文章列表）
- 文章详情页（Markdown 渲染、点赞、评论）
- 编辑器页面（文章创建、编辑、删除）
- 摄影页面（作品瀑布展示、筛选、灯箱详情）

### 2. 基础交互

- 首页锚点平滑滚动
- 主要模块动效与滚动显现
- AI 小组件交互优化（开关、输入、流式展示）
- 摄影页灯箱信息展示（时间、经纬度）

### 3. 数据与服务

- 本地 API 服务（文章 CRUD、点赞、评论）
- `db.json` + `public/posts/*.md` 的内容存储方案

## 阶段产出

- 可运行的博客前端页面与本地后端服务
- 基础内容管理能力
- 第一版摄影展示能力
- 开发文档目录（`docs/`）建立

## 已知问题（阶段内暂缓）

- 后端写接口缺少鉴权
- 前端存在敏感 key 暴露风险
- 渲染链路仍需进一步做 XSS 防护
- 缺少 SEO、RSS、归档、搜索等完整博客能力

## 阶段结束标准

- 主要页面可访问
- 关键交互可用
- 内容可发布与查看
- 文档可追踪后续阶段演进
